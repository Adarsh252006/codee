6. Write a Python program to demonstrate the Caesar Cipher technique. The program 
should:  
 Accept a plaintext message from the user.  
 Accept a key (shift value) from the user.  
 Encrypt the plaintext using the Caesar Cipher algorithm.  
 Display the original plaintext and the corresponding Cipher Text. 
# Accept plaintext from the user 
plaintext = input("Enter the plaintext message: ") 
# Accept the shift key 
key = int(input("Enter the shift value (key): ")) 
ciphertext = "" 
# Encrypt each character 
for char in plaintext: 
if char.isalpha(): 
if char.isupper(): 
ciphertext += chr((ord(char) - ord('A') + key) % 26 + ord('A')) 
else: 
ciphertext += chr((ord(char) - ord('a') + key) % 26 + ord('a')) 
else: 
# Keep spaces, numbers, and symbols unchanged 
ciphertext += char 
# Display the result 
print("\n----- Caesar Cipher Encryption -----") 
print("Original Plaintext :", plaintext) 
print("Cipher Text        :", ciphertext) 
Output: 
Enter the plaintext message: hello 
Enter the shift value (key): 3 ----- Caesar Cipher Encryption ----- 
Original Plaintext : hello 
Cipher Text        : khoor
