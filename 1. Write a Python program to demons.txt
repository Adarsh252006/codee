5. Write a Python program to demonstrate the URL Phishing Detection technique. The 
program should:  
 Accept a URL from the user.  
 Analyze the URL for phishing indicators.  
 Display whether the URL is legitimate or suspicious.  
 Provide the reason for the classification. 
from urllib.parse import urlparse 
# Accept URL from the user 
url = input("Enter a URL: ") 
# List to store phishing reasons 
reasons = [] 
# Parse the URL 
parsed_url = urlparse(url) 
domain = parsed_url.netloc 
# Check 1: HTTPS 
if not url.startswith("https://"): 
reasons.append("URL does not use HTTPS.") 
# Check 2: Presence of '@' symbol 
if "@" in url: 
reasons.append("URL contains '@' symbol.") 
# Check 3: Presence of IP address instead of domain name 
parts = domain.split(".") 
if len(parts) == 4 and all(part.isdigit() for part in parts): 
reasons.append("URL uses an IP address instead of a domain name.") 
# Check 4: Too many hyphens 
if domain.count("-") >= 2: 
reasons.append("Domain contains multiple hyphens.") 
# Check 5: Excessive URL length 
if len(url) > 75: 
reasons.append("URL is unusually long.") 
# Check 6: Too many subdomains 
if domain.count(".") > 3: 
reasons.append("URL contains too many subdomains.") 
# Display Result 
print("\n----- URL Phishing Detection Result -----") 
if len(reasons) == 0: 
print("The URL appears to be LEGITIMATE.") 
else: 
print("The URL appears to be SUSPICIOUS.") 
print("\nReasons:") 
for reason in reasons: 
print("-", reason) 
Output: 
Enter a URL: http://192.168.1.10/login@bank-security.com ----- URL Phishing Detection Result ----- 
The URL appears to be SUSPICIOUS. 
Reasons: - URL does not use HTTPS. - URL contains '@' symbol. - URL uses an IP address instead of a domain name.

import hashlib

def generate_hash(message):

message = input("Enter the original message: ") 
# Generate hash of the original message

print("Original SHA-256 Hash:")

# Modify the message 
modified_message = input("\nEnter the modified message: ") 
# Generate hash of the modified message

print("\nModified Message :", modified_message) 
print("Modified SHA-256 Hash:") 
print(modified_hash) 
# Verify integrity 
print("\n----- Message Integrity Verification -----") 
if original_hash == modified_hash: 
print("Integrity Verified.") 
print("The message has NOT been modified.") 
else: 
print("Integrity Verification Failed.") 
print("The message has been modified.")

10. Write a Python program to demonstrate the Digital Signature using RSA algorithm. 
The program should:  
 Accept a message from the user.  
 Generate RSA public and private keys.  
 Generate a digital signature using the private key.  
 Verify the signature using the public key and display the verification result. 
from cryptography.hazmat.primitives.asymmetric import rsa, padding 
from cryptography.hazmat.primitives import hashes 
# Generate RSA Keys 
private_key = rsa.generate_private_key( 
public_exponent=65537, 
key_size=2048 
) 
public_key = private_key.public_key() 
# Original message 
message = input("Enter the original message: ") 
# Generate Signature 
signature = private_key.sign( 
message.encode(), 
padding.PSS( 
mgf=padding.MGF1(hashes.SHA256()), 
salt_length=padding.PSS.MAX_LENGTH 
), 
hashes.SHA256() 
) 
print("\nDigital Signature Generated Successfully.") 
# Message to verify 
verify_message = input("Enter the message for verification: ") 
# Verify Signature 
try: 
public_key.verify( 
signature, 
verify_message.encode(), 
padding.PSS( 
mgf=padding.MGF1(hashes.SHA256()), 
salt_length=padding.PSS.MAX_LENGTH 
), 
hashes.SHA256() 
) 
print("\nSignature Verification Successful.") 
print("The message is authentic and has not been modified.") 
except Exception: 
print("\nSignature Verification Failed.") 
print("The message has been modified or the signature is invalid.") 
Output: 
Enter the original message: hello world 
Digital Signature Generated Successfully. 
Enter the message for verification: hello world 
Signature Verification Successful. 
The message is authentic and has not been modified.
